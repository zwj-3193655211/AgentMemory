# AgentMemory 功能说明书

> 项目名称：面向CLI Agent的本地语义化记忆系统
> 项目版本：v2.1.0
> 文档日期：2026年5月24日

---

## 一、产品概述

### 1.1 产品定义

AgentMemory 是一款本地部署的 AI 编程助手语义化记忆引擎，能够自动监控多个 CLI Agent 的会话日志，智能提取有价值的信息，并通过向量检索技术实现语义化搜索。

### 1.2 产品定位

| 定位维度 | 描述 |
|----------|------|
| **产品类型** | 本地化记忆管理系统 |
| **目标用户** | CLI Agent 用户（Claude Code、iFlow、Qwen 等） |
| **使用场景** | 个人桌面/笔记本环境 |
| **部署方式** | Docker + 本地运行 |

### 1.3 产品愿景

让 AI 编程助手具备"记忆能力"，告别重复提问，沉淀知识资产。

## 三、功能清单

### 3.1 核心功能列表

| 功能编号 | 功能名称 | 功能描述 | 优先级 |
|----------|----------|----------|--------|
| **F001** | 多 Agent 监控 | 自动监控 7 种主流 CLI Agent | P0 |
| **F002** | 消息实时存储 | 新消息即时写入数据库 | P0 |
| **F003** | 语义向量检索 | 基于向量的相似度搜索 | P0 |
| **F004** | 五大记忆库 | 自动分类保存知识 | P0 |
| **F005** | 智能分类 | 混合分类（规则+向量+LLM） | P0 |
| **F006** | 自动清理 | 过期数据自动删除 | P1 |
| **F007** | 数据统计 | 展示内存统计信息 | P1 |
| **F008** | 会话压缩 | 长会话摘要压缩 | P2 |
| **F009** | 数据导出 | JSON/CSV 格式导出 | P2 |
| **F010** | 健康检查 | 服务状态监控 | P1 |

### 3.2 功能详细说明

#### F001：多 Agent 监控

| 属性 | 描述 |
|----------|------|
| **功能说明** | 自动监控多个 CLI Agent 的会话目录，解析不同格式的日志 |
| **支持 Agent** | Claude Code、iFlow、Qwen、OpenClaw、Codex、Crush、WorkBuddy |
| **监控方式** | Java WatchService 文件系统监控 |
| **检测间隔** | 5 秒轮询 |
| **解析格式** | JSON、JSONL、Markdown、SQLite |
| **并发处理** | 线程池 + 文件锁 |

#### F002：消息实时存储

| 属性 | 描述 |
|----------|------|
| **功能说明** | 将解析后的消息实时存储到 PostgreSQL 数据库 |
| **写入方式** | JDBC + HikariCP 连接池 |
| **批量处理** | 缓冲 10 条或 5 秒批量提交 |
| **向量生成** | HTTP 调用 Embedding 服务 |
| **消息表** | messages |
| **索引** | HNSW 向量索引 |

#### F003：语义向量检索

| 属性 | 描述 |
|----------|------|
| **功能说明** | 将查询文本转换为向量，进行相似度检索 |
| **向量模型** | bge-small-zh-v1.5（512维） |
| **检索算法** | 余弦相似度 |
| **索引类型** | pgvector HNSW |
| **响应时间** | < 500ms |
| **过滤条件** | 支持按记忆库类型、Agent 类型过滤 |

#### F004：五大记忆库

| 记忆库 | 表名 | 保留期 | 核心字段 |
|----------|----------|--------|----------|
| 错误纠正 | error_corrections | 30天 | problem, cause, solution |
| 用户画像 | user_profiles | 永久 | category, items |
| 最佳实践 | best_practices | 30天 | scenario, practice |
| 项目上下文 | project_contexts | 永久 | project_path, tech_stack |
| 技能沉淀 | skills | 永久 | skill_type, description |

#### F005：智能分类

| 属性 | 描述 |
|----------|------|
| **功能说明** | 混合智能分类系统，三层决策 |
| **第一层** | 规则分类（关键词命中即返回） |
| **第二层** | 向量分类（相似度 >= 0.75 采用） |
| **第三层** | LLM 分类（Ollama 本地调用） |
| **置信度阈值** | 见下表 |
| **去重机制** | 相似度 > 0.95 视为重复 |

#### F006：自动清理

| 属性 | 描述 |
|----------|------|
| **功能说明** | 按记忆库保留期自动清理过期数据 |
| **执行周期** | 每小时执行 |
| **删除策略** | soft delete （标记位） |
| **会话清理** | 14 天无活动删除 |
| **日志记录** | 写入日志文件 |

#### F007：数据统计

| 属性 | 描述 |
|----------|------|
| **功能说明** | 展示系统数据统计信息 |
| **统计项** | 总会话数、总消息数、各记忆库数量、活跃 Agent 数 |
| **更新频率** | 实时 |
| **展示方式** | 仪表盘 + 数字卡片 |

#### F008：会话压缩

| 属性 | 描述 |
|----------|------|
| **功能说明** | 对长会话生成摘要，减少存储 |
| **触发条件** | 消息数 > 100 |
| **压缩方式** | 保留首尾消息 + 生成摘要 |
| **执行周期** | 每 2 小时 |

#### F009：数据导出

| 属性 | 描述 |
|----------|------|
| **功能说明** | 导出搜索结果或记忆库数据 |
| **导出格式** | JSON、CSV |
| **编码** | UTF-8 |
| **文件命名** | 按日期命名 |

#### F010：健康检查

| 属性 | 描述 |
|----------|------|
| **功能说明** | 检查各服务组件状态 |
| **检查项** | 数据库连接、Embedding 服务、会话处理器 |
| **状态码** | 200=正常，503=异常 |
| **端点** | /api/health |

| `/api/practices` | CRUD | 最佳实践库 | 否 |
| `/api/contexts` | CRUD | 项目上下文库 | 否 |
| `/api/skills` | CRUD | 技能沉淀库 | 否 |

### 5.2 接口详细定义

#### 5.2.1 健康检查

**GET** `/api/health`

响应：
```json
{
  "status": "ok",
  "timestamp": "2026-05-24T10:00:00Z",
  "services": {
    "database": "ok",
    "embedding": "ok"
  }
}
```

#### 5.2.2 统计数据

**GET** `/api/stats`

响应：
```json
{
  "totalSessions": 150,
  "totalMessages": 3500,
  "totalErrors": 45,
  "totalPractices": 32,
  "totalSkills": 28,
  "totalProfiles": 12,
  "totalContexts": 20,
  "activeAgents": 4
}
```

#### 5.2.3 语义搜索

**POST** `/api/search`

请求：
```json
{
  "query": "数据库优化",
  "top_k": 10,
  "type": "all"
}
```

响应：
```json
{
  "results": [
    {
      "id": "xxx",
      "title": "PostgreSQL 查询优化",
      "type": "best_practice",
      "content": "使用 EXPLAIN 分析...",
      "similarity": 0.92,
      "tags": ["database", "optimization"],
      "createdAt": "2026-05-20T08:00:00Z"
    }
  ]
}
```
