---

## 一、项目概述

### 1.1 项目定义

AgentMemory 是一个本地部署的 AI 编程助手语义化记忆引擎，能够自动监控多个 CLI Agent（如 Claude Code、iFlow、Qwen 等）的会话日志，提取有价值的信息存储到向量数据库，并支持语义化检索。

### 1.2 核心价值主张

| 价值主张 | 描述 |
|----------|------|
| 多源统一监控 | 打破 Agent 间的数据孤岛，统一管理多个 CLI Agent 的会话历史 |
| 语义智能检索 | 基于向量数据库的语义搜索，返回相关结果而非简单关键词匹配 |
| 知识自动沉淀 | 通过混合智能分类系统自动提取错误纠正、最佳实践、技能等知识 |
| 本地数据安全 | 所有数据存储在用户本地，保障隐私安全 |

| 用户群体 | 需求痛点 | 潜在价值 |

**AgentMemory 竞争优势**：
- ✅ 完全本地部署，数据安全可控
- ✅ 多 Agent 统一监控
- ✅ 语义检索 + 智能分类
- ✅ 零运营成本

### 4.3 市场机会

| 机会点 | 描述 | 规模估算 |
