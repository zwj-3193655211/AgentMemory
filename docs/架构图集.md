## 6. 会话处理时序图

```mermaid
sequenceDiagram
    participant User as 用户
    participant FW as FileWatcher
    participant SP as SessionProcessor
    participant MS as MemoryService
    participant HC as HybridClassifier
    participant EMB as Embedding Service
    participant DB as PostgreSQL
    
    User->>FW: 检测到日志文件变化
    FW->>SP: 触发解析任务
    
    SP->>SP: 解析不同格式的日志
    Note over SP: JSONL / Markdown / SQLite / JSON
    
    SP->>SP: 提取消息内容
    
    SP->>EMB: 发送文本进行Embedding
    EMB-->>SP: 返回向量 (512维)
    
    SP->>HC: 分类请求
    HC-->>SP: 返回分类类型 + 置信度
    
    alt 规则命中
        HC->>HC: 关键词匹配 → 直接分类
    else 向量相似
        HC->>DB: 查询相似记录
        DB-->>HC: 相似度 > 0.75
    else LLM兜底
        HC->>HC: 调用 Ollama 进行语义分析
    end
    
    SP->>MS: 存储消息 + 记忆
    
    MS->>DB: INSERT messages
    MS->>DB: INSERT 到对应记忆库
    
    User->>FW: 搜索查询
    FW->>EMB: Embedding 查询文本
    EMB-->>FW: 查询向量
    FW->>DB: 向量相似度搜索
    DB-->>FW: 返回 Top-K 结果
    FW-->>User: 显示搜索结果
```
